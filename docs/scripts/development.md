# Scripts de Desarrollo

## <a id="create-new-feature"></a> create-new-feature.sh

**Ubicación:** `scripts/bash/create-new-feature.sh`

Genera la estructura mínima para trabajar una nueva funcionalidad y sincroniza
las especificaciones iniciales.

```bash
./scripts/bash/create-new-feature.sh "nombre-de-feature"
```

## <a id="implement"></a> implement.sh

**Ubicación:** `scripts/bash/implement.sh`

Coordina la fase de implementación de una feature, ejecutando validaciones y
sincronizaciones necesarias.

```bash
./scripts/bash/implement.sh
```

## <a id="setup-plan"></a> setup-plan.sh

**Ubicación:** `scripts/bash/setup-plan.sh`

Crea un plan de trabajo basado en las especificaciones vigentes y prepara el
contexto del agente.

```bash
./scripts/bash/setup-plan.sh
```
