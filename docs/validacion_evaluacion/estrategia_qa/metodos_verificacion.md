# Métodos de Verificación (ISO 6.5.2.2)

- **Inspección:** Revisiones documentales y walkthroughs.
- **Análisis / Simulación:** Modelos, prototipos y cálculos.
- **Demostración:** Presentaciones funcionales controladas.
- **Prueba:** Ejecución de casos de prueba automatizados o manuales.

Registrar resultados en `resultados_pruebas/` y mantener trazas en `trazabilidad_pruebas/`.
