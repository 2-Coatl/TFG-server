# Gobernanza de Requisitos

Define procesos, checklists y estándares para asegurar la conformidad con ISO/IEC/IEEE 29148 y la trazabilidad integral.

## Contenido

- `procesos/`: procedimientos operativos (gestión de cambios, revisión documental, baselines).
- `checklists/`: listas de verificación para requisitos individuales y conjuntos.
- `estandares/`: guías y reglas normativas.
- `baselines/`: registros de baselines aprobados y su contexto.
- `planificacion/`: roadmap maestro y cadencia de releases.
