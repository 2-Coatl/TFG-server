# Proceso de Gestión de Cambios de Requisitos

1. **Solicitud**
   - Iniciar con `plantillas/gobernanza/plantilla_plan_gestion_cambios_requisitos.md`.
   - Registrar en `tareas_analisis/gestion_ciclo_vida_requisitos/t_5.4_evaluar_cambios/`.
2. **Análisis de Impacto**
   - Evaluar trazas en `requisitos/trazabilidad_general.md`.
   - Identificar pruebas afectadas en `validacion_evaluacion/casos_prueba/`.
3. **Aprobación**
   - Documentar decisión en `t_5.5_aprobar_requisitos/`.
   - Actualizar `requisitos/registro_maestro.md` y baselines vigentes.
