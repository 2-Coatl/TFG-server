# Requisitos de Stakeholders (StRS)

Clasifica las expectativas de usuarios y partes interesadas.

## Estructura

- `por_rol/`: requisitos según rol (gerente, vendedor, etc.).
- `contexto_uso/`: escenarios, personas y entornos de uso.
- `trazabilidad_stakeholders.md`: mapea NEED → STK → REQ.

## Estándares

- ISO/IEC/IEEE 29148 Clause 9.4.
- BABOK v3: Elicitation & Collaboration (KA 4).
- PMBOK Guide 7: Métodos de involucramiento de stakeholders.
