# Requisitos Integrados (StRS, SyRS, SRS)

Esta carpeta agrupa las especificaciones de requisitos siguiendo ISO/IEC/IEEE 29148 Clauses 9.3-9.6.

## Subcarpetas
- `requisitos_negocio/`: objetivos estratégicos (BRS).
- `requisitos_stakeholders/`: StRS clasificados por rol.
- `requisitos_solucion/`: SyRS + SRS con separación funcional/no funcional.
- `requisitos_transicion/`: capacidades temporales para migraciones.
- `por_dominio/`: vistas complementarias (solo referencias, sin duplicar contenido).

## Artefactos transversales
- `trazabilidad_general.md`: matriz Need → Requirement → Design → Test.
- `registro_maestro.md`: inventario maestro alineado con atributos ISO 5.2.8.
- `casos_de_uso.md`: guía completa para especificar e ilustrar casos de uso.

## Referencias
- BABOK v3: KA 5 y KA 7.
- PMBOK Guide 7: Artefactos de requisitos y métodos de priorización.
- ISO/IEC/IEEE 29148: Stakeholder & System Requirements Definition (6.3, 6.4).
