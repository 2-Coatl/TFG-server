# Tareas de Análisis (BABOK v3)

Organiza las 30 tareas de BABOK en 6 áreas de conocimiento, mapeadas a los procesos ISO 29148.

## Directorios principales
- `planificacion_y_monitoreo/`
- `elicitacion_colaboracion/`
- `gestion_ciclo_vida_requisitos/`
- `analisis_estrategico/`
- `analisis_requisitos_diseno/`
- `evaluacion_solucion/`

Cada subcarpeta debe documentar actividades, técnicas y artefactos con referencias a plantillas y resultados.
