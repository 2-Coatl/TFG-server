# Plantilla - Plan de Gestión de Cambios de Requisitos

**Propósito:** Definir el proceso ligero para evaluar, aprobar y comunicar cambios de requisitos conforme a ISO/IEC/IEEE 29148.

## Flujo de cambios

1. **Solicitud de cambio:** Registrar en `requisitos/registro_maestro.md` con estado *Propuesto*.
2. **Análisis de impacto:** Documentar en la tabla siguiente y referenciar ADR si corresponde.
3. **Aprobación:** Comité definido en `gobernanza/procesos/proceso_revision_documental.md`.
4. **Implementación y seguimiento:** Actualizar pruebas, trazabilidad y métricas.

## Tabla de control

## Comunicaciones

- Canal y frecuencia de comunicación
- Stakeholders informados

## Métricas

- Tiempo promedio de evaluación
- Porcentaje de cambios aprobados

## Revisión

- Fecha de última revisión del plan
- Lecciones aprendidas asociadas (`tareas_analisis/analisis_estrategico/registro_riesgos.md`, `requisitos/trazabilidad_general.md`)
