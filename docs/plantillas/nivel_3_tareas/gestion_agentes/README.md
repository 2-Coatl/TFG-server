# Plantillas de Gestión de Agentes

Conjunto de formatos para coordinar análisis, planes y ejecuciones asistidas por agentes.
Incluye instrucciones de delegación, plantillas de contexto y un catálogo de comandos
reutilizables (`commands/`).

## Plantillas destacadas
- `agent-file-template.md`: ficha base para registrar contexto de agentes.
- `delegation-template.md`: guía para delegar tareas complejas.
- `plan-template.md` / `plan-template-build.md`: estructuras para planes iterativos.
- `spec-template.md` / `spec-template-build.md`: soporte para especificaciones guiadas.
- `commands/`: prompts operativos (`analyze`, `plan`, `implement`, etc.).
